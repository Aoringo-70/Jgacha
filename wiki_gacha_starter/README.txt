WIKI GACHA - はじめかた

■ カードの追加・変更
1. 画像を images フォルダに入れます。
2. cards.js の cards リストにカードを追加します。rarity は LR / UR / SSR / SR / R / UC / C から指定します。
3. id はカードごとに重複しない値にしてください。

■ 排出確率
app.js の RARITY_WEIGHTS で調整できます。初期値は LR:1 / UR:3 / SSR:6 / SR:12 / R:18 / UC:25 / C:35 です。全レアリティが登録されている場合、約 LR 1%、UR 3%、SSR 6%、SR 12%、R 18%、UC 25%、C 35% になります。
登録されていないレアリティは抽選対象から外し、残りのレアリティで確率を自動調整します。先にレアリティを抽選し、そのレアリティ内のカードを選ぶため、各レアリティに登録したカード数によってレアリティ確率が変わりません。

■ 機能
・1回で確率設定に沿ってランダムに5枚引きます。
・ガチャ画面でレアリティ別の排出確率を確認できます。
・図鑑はレアリティ別に絞り込めます。
・同じカードを複数回引くと所持枚数が増えます。
・所持記録は利用中のブラウザ内に保存され、他の端末とは共有されません。

■ 公開
GitHub Pages などの静的ホスティングにアップロードしてURLを共有できます。URLを知っている人向けの公開は、URLが広まると他の人もアクセスできます。
